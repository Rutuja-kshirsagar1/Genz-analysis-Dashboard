# Genz-analysis-Dashboard
 Gen Z Aspirations Dashboard
Developed an interactive dashboard to visualize and compare the mission aspirations of Gen Z individuals with the expectations and aspirations of their managers. The project involved collecting and analyzing survey data to identify key motivational drivers, career goals, and workplace expectations from both perspectives. Using data visualization tools, the dashboard highlights alignment gaps, shared values, and actionable insights to foster better intergenerational understanding and workplace synergy.
